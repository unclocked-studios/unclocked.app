Chrome extension

Image to Base64, ready for the web.

Frame64 converts images to Base64 data URLs, optimizes file size, resizes, crops, and compares quality, all in your browser. Your images are processed on your device and are not uploaded to a conversion server.

Add to Chrome ↗ See plans and pricing

Start with the free version, or try everything free for 14 days. Available on the Chrome Web Store.

What it does

Everything between a file and a data URL.

Convert and decode

Drop, browse, or paste an image to get PNG, JPEG, or WebP output as Base64. Decode existing Base64 to preview and download the image.

Optimize file size

Resize by width, height, or exact size, adjust quality, and aim for a target file size with JPEG or WebP.

Compare quality

Compare the original and processed image with a draggable divider, synced zoom and pan, and live size numbers.

Export Studio

Generate several sizes and formats from one source, and save your export settings as recipes you can reuse.

Ready-to-paste code

Copy the result as a Data URL or raw Base64, or as HTML, CSS, JavaScript, or Markdown snippets.

Private by design

Images are processed locally in your browser. PDF pages can be converted to images locally too.
