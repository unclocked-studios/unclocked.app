Unclocked 3D Heatmap

Frequently asked questions

Answers about data, features, plans, and performance. They describe version 1.2.0.0, the current release on Microsoft Marketplace. See the changelog for what changed.

Getting started

What is Unclocked 3D Heatmap?

A custom visual for Microsoft Power BI. It draws each warehouse location as a bin, from your coordinates or from racks you draw in the visual, and colors it by a numeric measure, so you can see where inventory, activity, or exceptions are concentrated. Explore it in 3D, as a 2D plan, or over time, filtered by the rest of your report.

How do I add it to a report?

In Power BI, open Get more visuals from the Visualizations pane, search for Unclocked 3D Heatmap, and add it. You can also install it from its Microsoft Marketplace listing. The how-to guide walks through setup.

Can I try it before using my own data?

Yes. Download the sample report and open it in Power BI Desktop, or build your own view from the sample CSV (2,208 locations) using the sample setup guide. The layout builder also has a built-in tutorial on a practice warehouse.

Does it work in Power BI Desktop and the Power BI service?

Yes. Reports built in Power BI Desktop work the same way when published to the Power BI service. Licensing is checked differently in a few environments; see Plans and licensing.

Your data

What data does the visual need?

One row per warehouse location, with a unique Location ID and a numeric measure in Heat Value, plus either X Coordinate and Y Coordinate or a layout drawn in the visual. Optional fields add height, bin sizes, category filters, a Time field for playback, tooltip measures, threshold measures, and an exception score. See the field reference.

Do I need coordinates?

No. With the layout builder, report authors draw racks, bays, and levels over the floor plan, and the visual creates every Location ID from a naming pattern and places your data on it. It can suggest a pattern from your existing IDs and explains why any ID didn't match. If you'd rather not draw it, our warehouse mapping service can turn an AutoCAD drawing into a coordinate CSV.

Which units and coordinate system should I use?

Any unit works, as long as coordinates and bin sizes use the same one. X and Y mark the starting corner of each bin's footprint, and Z is its base height. The visual centers the layout automatically, so coordinates don't need to start at zero. The layout builder works in inches, feet, centimeters, or meters, and accepts sizes such as 3'10" or 1.2m.

What can I use as the Heat Value?

Any numeric measure that can be evaluated per location, such as on-hand quantity, picks, utilization, days on hand, dwell time, shortage quantity, or an exception count. Use a measure rather than a column when the value should respond to report filters.

Why don't my empty locations appear?

Power BI leaves out rows where every measure is blank. Right-click Location ID in the visual's Build pane and turn on Show items with no data. With the layout builder, drawn locations without data appear anyway, as outlines, the empty color, or hidden, set in Format visual → Layout.

What happens if a Location ID appears more than once?

The visual keeps the first row for that ID and lists the duplicate IDs in a warning, so you can fix them in your data.

Why does the hover popup show fewer details than before?

Since version 1.2, hovering shows only the measures in Tooltip measures, in the order you add them. Add the measures you want there. To show the Location ID, add a text measure such as Tooltip Location = SELECTEDVALUE(locations[Location]). A location's details panel is unchanged.

Using the visual

Does it work with slicers and other visuals?

Yes. The warehouse and its colors follow the report's filters and slicers. Clicking a location can stay inside the visual, use Power BI selection so other visuals respond, or filter the report by that location; choose this in Format visual → Interaction → Bin click behavior. Right-click a location for the Power BI context menu.

Can I see inside the racks?

Yes. Turn on the cutaway in Format visual → Cutaway, then use the level slider to show the warehouse up to a level, or Only this level to show one level by itself. Colors stay on one scale as the cut moves.

Is there a 2D floor plan view?

Yes. Choose 2D under View tools → Display for a flat plan you can pan, zoom, and rotate. Where levels share a footprint, 2D stack color colors each stack by its top bin, maximum, or average, and the cutaway shows a single level's plan.

Can I see how activity changes over time?

Yes, on Professional. Add a date or period to the Time field to replay the heatmap period by period, or use Compare to color each location by its change from the previous, first, or a chosen period. See playback and compare.

Can it show which aisles are congested?

Yes, on Professional. The congestion floor shades the floor in front of busy pick faces and spreads it along the aisles, following your filters and playback. It's an activity indicator, not a measurement of people or delays.

How do I find or select locations?

Type part of a Location ID in Find a location to focus on it. To select several, hold Shift and drag over the warehouse, or use View tools → Select an area; a summary shows their count, average, range, and total.

Can I save camera views?

Yes. Under View tools → Saved views, choose Save current and name the view. Keep up to 100, and save the report so other viewers get them. The visual also remembers your last view when you return to the page.

Can it point out problem locations?

Yes. Turn on Format visual → Exceptions → Show exception finder to list locations at or above a value, at or below a value, zero, or blank, or to rank a positive DAX exception score. Select a result, then Focus in 3D to frame it.

Can the color thresholds change with my slicers?

Yes. Set Heat scale → Threshold source to Measures and bind DAX measures to the Low, Medium, High, and Critical threshold fields. Each must return the same number for every location.

Can I show a floor plan under the bins?

Yes. In Format visual → Scene, turn on the floor image and paste the image as a PNG, JPEG, or WebP data URL. Line it up with your coordinates, or match its proportions and set its scale in the layout builder. Links to images on other sites aren't supported.

Does it support dark mode and high contrast?

Yes. Choose Neutral light, Neutral dark, or Classic purple in Format visual → Scene → UI theme. The visual also follows Power BI's high-contrast themes and supports keyboard focus.

Plans and licensing

What can I do on the free plan?

Color up to 2,500 locations with the layout builder, cutaway, area selection, saved views, exceptions, and the other viewing tools. Locations past the limit are drawn pale gray, and drawn locations without data never count. Playback, compare, and the congestion floor need Professional.

What does Professional add?

It removes the 2,500-location limit, so the report author sets the scene size with Max displayed bins, up to 100,000, and it adds playback, compare, and the congestion floor. Professional is licensed per user through Microsoft Marketplace; see plans and pricing.

Does every report viewer need a license?

Each person who needs Professional, including report viewers, needs an assigned license. Buying a license for the report author doesn't cover the people the report is shared with. See how to assign licenses.

What happens when Power BI Desktop is offline or signed out?

If a Professional license was verified on the same device in the last 7 days, Professional stays available and the status shows Professional (offline). Otherwise the free plan applies until the license can be checked again.

Where can't the license be checked?

Power BI Report Server, Publish to web, app-owns-data embedding, and national clouds don't support license checks for visuals, so the free plan applies there. Contact us about these deployments.

Performance and privacy

How large a warehouse can it handle?

Up to 100,000 locations on Professional. How smooth it feels depends on the report, the device, and the browser. Start with the Balanced performance preset, and switch to Performance, turn off bin outlines and hover tooltips, or filter the report if navigation slows. Playback loads locations × periods, so very long timelines take longer.

Does the visual send my data anywhere?

No. The visual makes no network requests and doesn't send your warehouse data, coordinates, layouts, or measures to Unclocked Studios. It only stores saved views, your last view, and the date of the last license check in Power BI's storage for visuals. See the privacy policy.
