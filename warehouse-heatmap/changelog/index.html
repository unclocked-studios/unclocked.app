Unclocked 3D Heatmap

Changelog

What changed in each version of the visual, newest first. Dates are when each version was completed; a version reaches Microsoft Marketplace after Microsoft reviews it.

Versions: 1.2 (in review) · 1.1.0.5 (current) · 1.1.0.3 · 1.0.0.1

In review · pending Microsoft approval

Version 1.2

Completed October 13, 2026

These features aren't available yet. They arrive when Microsoft approves version 1.2 and it is published on Marketplace. Until then, the guide and FAQ describe version 1.1.0.5.

New in Free and Professional

  • Layout builder: no coordinates needed. Report authors draw racks, bays, and levels over the floor plan inside the visual, and it creates every Location ID from a naming pattern and places your data on it. It can suggest a pattern from your existing IDs, explain why an ID didn't match, and export the locations as a CSV. A built-in tutorial practices on a sample warehouse.
  • Cutaway: a level slider shows the warehouse up to a chosen level so you can see inside racks, or isolates a single level.
  • Area selection: Shift-drag to select every location in a box and see its count, total, and average.
  • Named saved views: save up to 100 camera views by name, replacing the three P1–P3 presets, which carry over.
  • 2D plan options: color each stack by its top bin, its maximum, or its average, and show aisle labels on builder layouts.
  • Remembers your last view when you return to a report page, without changing the report's default.
  • Redesigned viewer with one status card, collapsible tool sections, and shared light, charcoal, and high-contrast palettes.

New in Professional

  • Playback and compare: add a date or period to the new Time field to play the heatmap over time, or color each location by how much it changed.
  • Congestion floor: shades the aisles where activity happens in front of busy pick faces, not just the busy shelves.

Change to check in existing reports

  • Hover tooltips will show only the measures in Tooltip measures. To keep the Location ID in the hover popup, add a text measure for it to that field well. The selected-location panel is unchanged.
Current version

Version 1.1.0.5

Completed October 4, 2026

Licensing

  • Every active Professional plan assigned to a user now unlocks Professional, including trials and seat tiers added later. Earlier versions recognized only the original plan.
  • If Power BI Desktop is signed out or offline, a Professional license verified on the same device in the last 7 days keeps all bins available, shown as Professional (offline).
  • Pages with a Professional license load once instead of drawing the visual twice while the license is checked.

New

  • 2D navigation pad: pan the plan with arrows, rotate it in 90° steps, and reset with the center button. The arrow keys also pan.
  • The visual takes its current name, Unclocked 3D Heatmap. Existing reports keep working.

Improvements and fixes

  • Faster updates: resizing no longer reprocesses data, and hovering and clicking bins do less work.
  • Tooltips and the selected-location panel show the data's Z and height rather than values multiplied by Vertical scale.
  • A duplicated Location ID keeps its first row and is listed in a warning, instead of the location disappearing.
  • Category filter checkboxes toggle with a single click, and Escape clears only the search box.
  • Power BI filter click behavior filters other visuals without also cross-highlighting them.
  • A camera zoomed onto its own target point, or a default view saved there, no longer gets stuck.
  • The visual shows a message and recovers if the browser's graphics context is interrupted.
  • Manual thresholds entered out of order show a warning instead of being reordered silently.

Version 1.1.0.4, completed October 3, was withdrawn before review and never published; its changes are included here.

Version 1.1.0.3

Completed September 16, 2026

New

  • Thresholds from DAX: set Threshold source to Measures to drive the Low, Medium, High, and Critical thresholds from measures that follow your slicers. Scale details in the legend shows the values in use.
  • Exception finder: list locations above or below a cutoff, zero, or blank, or rank them by a DAX exception score, then focus on a result in 3D.
  • Tooltip measures: add supporting measures, with their Power BI formats, to a location's details.
  • UI themes: Neutral light (the new default), Neutral dark, and Classic purple, with controls that adapt to small visuals.
  • Fit current layout frames the locations currently shown.
  • Settings to hide the status and license boxes, which now start collapsed.

Improvements

  • The camera stays where it is when report slicers or category filters change.
  • Cross-highlighting keeps the full layout and dims locations that aren't highlighted.
  • Locations with invalid coordinates are reported instead of being drawn at zero.
  • If the license can't be checked, the visual says so and applies the 2,500-bin limit.

Version 1.0.0.1

Completed June 29, 2026

The first release, under the visual's original name.

  • A 3D warehouse model built from X, Y, and Z coordinates, with optional bin sizes.
  • Heat coloring by any numeric measure, as a gradient or color bands.
  • 3D and 2D views, Location ID search, and three category filters that dim or hide other locations.
  • A saved default view and three camera presets.
  • Power BI selection, filtering, and context menu support.
  • A floor plane with an optional floor-plan image.
  • Performance presets for large layouts, and a free plan of up to 2,500 bins.
