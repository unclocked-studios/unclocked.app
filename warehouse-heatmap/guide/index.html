Unclocked 3D Heatmap guide

How to use Unclocked 3D Heatmap

Set up the visual in Power BI, place your warehouse locations, and explore them in 3D, in 2D, and over time. This guide describes version 1.2.0.0, the current release on Microsoft Marketplace. See the changelog for what changed.

Rolling out (October 18, 2026): Version 1.2.0.0 is published on Microsoft Marketplace, but Power BI can take up to two weeks to deliver it. Until about November 1, Get more visuals may still add version 1.1.0.5. If the Format pane has no Cutaway section, you have the earlier version: check back in a few days and restart Power BI Desktop. Reports that use the visual switch to 1.2 on their own once it arrives.

On this page: 1. Add the visual · 2. Place your locations · 3. Add your fields · 4. Explore the warehouse · 5. Cutaway · 6. Playback and compare · 7. Congestion floor · 8. Heat scale · 9. Exceptions · 10. Format and plans

Step 1

Add the visual to your report

  1. In Power BI Desktop, open a report and select Get more visuals in the Visualizations pane.
  2. Search for Unclocked 3D Heatmap and select Add.
  3. Select the new icon in the Visualizations pane to place the visual on the page.
  4. Make the visual large enough for the warehouse and its controls.

Prefer to start from a finished example? Open the sample report in Power BI Desktop, or load the sample CSV and follow along.

Step 2

Place your warehouse locations

The visual needs to know where every location is. Use coordinates from your data, or draw the racks in the visual with the layout builder.

Option A: coordinates in your data

Use one row per physical bin or location, with its position and the value to color it by.

Example rows: three locations in one aisle

  • X runs across the warehouse and Y along the floor; together they mark the starting corner of the bin's footprint. Z is its base height, and missing Z means floor level.
  • Width extends from X, length from Y, and height upward from Z. Use one unit for everything; the visual centers the layout itself.
  • Give every location a unique ID. If an ID appears twice, the visual keeps the first row and lists the duplicates in a warning.
  • Keep the layout in its own location table, related one-to-many to your inventory or activity data, and use a measure for Heat Value so it responds to filters.
  • To show empty locations, right-click Location ID in the Build pane and turn on Show items with no data.

Option B: draw the layout in the visual

With the layout builder, your data only needs Location ID and Heat Value. You draw the racks; the visual creates every location and its ID from a naming pattern, and places each row of data on the location with the same ID. The layout builder is experimental and under active development, so its controls may change in later versions.

  1. Add Location ID and Heat Value, and leave X and Y empty.
  2. In report edit mode, select the visual and click Edit in its header. The plan opens with the Layout builder panel. New to it? Start tutorial practices on a sample warehouse without changing your report.
  3. Choose your Units. To trace a floor drawing, add it in Format visual → Scene, then use Match image proportions and Set scale by clicking two points a known distance apart.
  4. Choose Rack and drag along the floor to draw a rack; the length sets the number of bays. Set bays, levels, level heights, and depth in the Rack tab.
  5. Set the ID pattern so it matches your data, such as {aisle}-{bay:2}-{level:A} for A-07-C. While IDs don't match, Suggested ID pattern reads one from your data, and each unmatched ID says why.
  6. Build rows quickly with Duplicate, Add copies, and Pair across aisle or Pair back to back.
  7. Check the Data tab for how many locations were placed, then click Back to report. Changes save to the report as you work, and report viewers never see the builder.

The builder has two views of the same tools: Classic (the default) and Modern, which is experimental. Export saves the layout as JSON, or the locations as a CSV you can check against your WMS. Format visual → Layout → Layout source decides whether coordinates or the drawn layout apply; reports built with coordinates keep working.

Have the layout only in an AutoCAD drawing and prefer not to draw it? Our warehouse mapping service can prepare the coordinate CSV.

Step 3

Add your fields

Select the visual and drag fields into these wells in the Build pane.

Field wells in Unclocked 3D Heatmap
Field wellWhat it does
Location ID (required)Unique name for each location, used for search, selection, details, filtering, and matching the drawn layout.
Heat Value (required)The numeric measure that colors each location.
X Coordinate, Y Coordinate (required unless you draw the layout)Position on the warehouse floor.
Z Coordinate (optional)Base height for stacked levels. Missing Z means floor level.
Bin Width, Bin Length, Bin Height (optional)Size of each location. Without them, the defaults in Format visual → Bins apply.
Category Filter 1, 2, and 3 (optional)Fields such as aisle, level, zone, or location type that viewers can filter by inside the visual.
Time (optional)A date or period, such as Week or Shift, for playback. See step 6.
Pick-face direction (optional)Which side each location is picked from, for the congestion floor with coordinate data. See step 7.
Tooltip measures (optional)The measures shown when you hover over a location, in field-well order, and in its details.
Low, Medium, High, and Critical threshold (optional)DAX measures for color thresholds that follow slicers. See step 8.
Exception score (optional)A DAX measure for ranking exceptions. See step 9.

Hover popups show only the fields in Tooltip measures. To include the Location ID, add a text measure such as Tooltip Location = SELECTEDVALUE(locations[Location]).

Step 4

Explore the warehouse

Move around

  • In 3D, drag with the left mouse button to orbit, use the wheel to zoom, and drag with the middle button to pan.
  • In 2D, dragging pans. The pad in the bottom-right corner pans with its arrows and rotates the plan in 90° steps; its center button resets the rotation and fits the floor.
  • Hover over a location for its tooltip measures. Select it to see its details beside the warehouse, and right-click for the Power BI context menu.

Use View tools

Open View tools in the upper-right corner. Each section folds on its own.

  • Display: switch between 3D and the 2D plan. The home icon saves the current view as the report's default when there is none, returns to it on a click, and replaces it on Shift-click.
  • Camera: Iso, Top, and Front views, and Fit warehouse to frame the locations shown.
  • Saved views: Save current, give the view a name, and select it later to return. Rename or delete views, and keep up to 100. Save the report to keep them for other viewers.
  • Plan View: Fit to floor frames the whole floor in 2D.
  • Selection: Select an area, then drag over the warehouse. You can also hold Shift and drag.
  • Visible layers: show or hide the overview card, navigation help, location data, the legend, the level cutaway, and the congestion floor.
  • Filters: each category field gets a dropdown. Click values to add or remove them, and Clear to show all. Non-matching chooses whether other locations are dimmed or hidden.

Search, select, and connect

  • Type part of a Location ID in Find a location, then choose a suggestion or press Enter to focus on it.
  • An area selection summarizes the locations inside it: how many have a value, their average, range, and total, and the top three. Zoom to selection frames them.
  • Format visual → Interaction → Bin click behavior chooses whether a click stays inside the visual (Visual only), uses Power BI selection so other visuals respond, or applies a Power BI filter. Area selections follow the same setting.
  • The visual remembers your last view on each device when you come back to the page, without changing the report's default. Format visual → Camera → Opening view sets whether the report opens in 3D or 2D.

Stacked levels in 2D

Where levels share a footprint, the top bin shows by default. Format visual → Scene → 2D stack color can color each stack by its Maximum or Average instead, so a busy lower level shows in the plan. Drawn layouts can also show aisle labels. To see one level by itself, use the cutaway.

Step 5

See inside the racks with the cutaway

Turn on Format visual → Cutaway → Show cutaway. The visual needs locations at two or more heights. A level control appears on the left edge:

  • Drag the slider, or use the arrows, to show the warehouse up to a level. All shows every level again.
  • Only this level shows just the level the slider is on. In 2D, that is the level's own plan.
  • Cut-away bins hides the cut levels or draws them as faint outlines in 3D. Colors stay on one scale as the cut moves.
  • Start level and Mode set what the report shows when it opens and in exports.
Step 6 · Professional

Play the heatmap over time

Add a date or period field, such as Week, Date, or Shift, to Time. A playback bar appears once there are two or more periods.

  • Play, Pause, and step one period at a time, or drag the slider to any period. Speed runs from 0.5x to 4x, and Loop starts over after the last period.
  • Locations never move during playback; only their colors change, on one scale across the whole timeline.
  • Compare colors each location by its change instead: vs previous, vs first, or vs a period you choose. Decreases use the low color, increases the critical color, and no change is gray.
  • Tooltips, details, the legend, and exceptions follow the period on screen. Format visual → Playback sets the start period, speed, loop, autoplay, and fading.

Sort a text period, such as "Week 01", by a date or number column in your model so it plays in order. Large warehouses with many periods take longer to load; the Playback value limit in Performance settings caps how much is loaded. On the free plan the bar is locked and the visual shows one period.

Step 7 · Professional

Read the congestion floor

Turn on Format visual → Congestion → Show congestion floor to shade the floor where activity happens, using Heat Value, such as picks or visits per location.

  • Each location's value goes onto the floor in front of the side people pick it from, then spreads along the aisle through open floor, never through a rack. Spread sets how far: Short, Medium, or Long.
  • Drawn layouts know each rack's pick face. With coordinates, add Pick-face direction with values such as Right, Left, Up, or Down (relative to the original floor plan); without it, the floor is shaded around each location.
  • The busiest floor on screen is always the strongest color. The floor follows slicers, filters, and playback periods.

The congestion floor is an activity indicator. It doesn't measure people, delays, or walking routes.

Step 8

Set the heat scale

The heat scale in Format visual → Heat scale turns Heat Value into color. Open Scale details in the legend to see the values in use.

  • Gradient blends smoothly between the low, medium, high, and critical colors; Bands changes color at each threshold; Normalized gradient spaces the colors evenly across the displayed range.
  • Auto range from visible data fits the scale to the locations shown, or set Manual minimum and Manual maximum to compare pages on one scale. Cap outliers and Treat zero as empty refine it.
  • Threshold source: Manual uses the values set in the Format pane; Measures uses DAX measures in the threshold wells, so targets follow slicers. Each must return the same number for every location.
Step 9

Find exceptions

Turn on Format visual → Exceptions → Show exception finder to list locations At or above or At or below a cutoff, Zero, or Blank, or to rank a positive DAX exception score. Select a result to see its details, then Focus in 3D to frame it. The cutoff is separate from the color thresholds.

Step 10

Format, performance, and plans

  • Scene: colors, the floor plane and floor image, bin outlines and opacity, the UI theme (Neutral light, Neutral dark, or Classic purple), 2D stack color, and aisle labels.
  • Floor image: paste a PNG, JPEG, or WebP image as a data URL, then line it up with your coordinates, or set its scale in the layout builder. Links to images on other sites aren't supported.
  • Bins: default sizes, Vertical scale, and Max displayed bins.
  • Performance: start with Balanced. If movement slows, choose Performance, turn off bin outlines and hover tooltips, or filter the report to one area.

Free and Professional

The free plan colors up to 2,500 locations and includes the layout builder, cutaway, area selection, and saved views. Locations past the limit are drawn pale gray, and layout locations without data never count. Professional removes the limit, up to the Max displayed bins you set (at most 100,000), and adds playback, compare, and the congestion floor. See plans and pricing and license assignment.
