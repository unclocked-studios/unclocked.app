LoopDeck Privacy Policy

Last updated: October 6, 2026

Introduction

LoopDeck is a Chrome extension created by Unclocked Studios LLC to help users create screen profiles, cycle through dashboard URLs, and manage shared display computers with Display Manager. This Privacy Policy explains how LoopDeck handles data.

Data Collection

Unclocked Studios LLC does not receive your dashboard URLs, profiles, or settings, and LoopDeck does not collect browsing history, website content, analytics, or usage activity.

Local Storage

LoopDeck stores extension settings in your browser using Chrome extension storage. This may include screen profile names, dashboard nicknames, dashboard URLs, timer settings, and feature preferences. This data is used only to provide LoopDeck's features.

Chrome Sync and Display Manager

If you turn on Profiles & Sync, or use Display Manager, LoopDeck saves the relevant data to Chrome Sync so it is available on your other computers signed in to the same Google account. For Display Manager, this includes workspaces (dashboard URLs, names, and playback settings), display names, group assignments, playback and refresh commands, and status reports from each display. Chrome Sync is provided by Google and is governed by your Google account settings and Google's privacy policy. Unclocked Studios LLC does not receive this data.

Site Access

LoopDeck requests site access for the dashboard URLs you add. On a dedicated display computer, you can optionally allow access to all websites so future dashboard changes do not need another approval. Site access is used only to run dashboard timers, Smart Pause, tab cycling, fullscreen behavior, and related features. LoopDeck does not use it to collect or transmit website content.

Trials and Payments

LoopDeck uses ExtensionPay and Stripe for trials and paid plans. To start a trial or purchase a plan, you sign in with your email address through ExtensionPay, which is used to verify your trial or plan on each computer. Payment processing is handled by those services. LoopDeck does not receive or store credit card numbers or payment details.

Data Sharing

We do not sell, share, or transfer user data.

Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated effective date.

Contact

If you have questions about this Privacy Policy, contact us at support@unclocked.app.
