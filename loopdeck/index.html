LoopDeck Support

Help and privacy resources for LoopDeck, the dashboard cycling extension from Unclocked Studios.

Contact Support

For bugs, feature requests, or setup questions, email support@unclocked.app.

Common Questions

Does LoopDeck collect browsing history?

No. LoopDeck stores screen profiles, dashboard URLs, timers, and preferences in Chrome storage. If you use Profiles & Sync or Display Manager, that data syncs through your Google account with Chrome Sync. We do not receive it.

Why does LoopDeck request site access?

Site access is requested for the dashboard sites you add. It allows LoopDeck to run timers and Smart Pause on those tabs. On a dedicated display computer, you can optionally allow all websites so future dashboard changes do not need another approval.

What do I need for Display Manager?

Display Manager requires a paid plan or an active trial. Install LoopDeck on each display computer, sign in to Chrome Sync with the same Google account, and sign in to the same LoopDeck account through ExtensionPay. See the LoopDeck product page for plans.

How does Smart Pause work?

Smart Pause temporarily suspends cycling when someone interacts with a dashboard, then resumes after the idle timer expires.
